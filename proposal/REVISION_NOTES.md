# 学术写作修订说明

本轮修改保持研究方向、技术方案、三个拟创新点、全部表格内容和引用键不变，`references.bib` 未修改。

- **Research narrative：** 将背景部分改为“任务专用模型泛化受限 -> 基础模型引入 -> CFM 物理结构接口”的连续论证，减少分类式说明，并明确 WiFo-like 只是受控基线而非全文研究背景。
- **Related Work：** 将 WFM 发展改写为“前期技术积累 -> 概念形成 -> 快速扩展与专门化”，将 CFM 综述从逐模型罗列改为围绕统一表示、异构扩展、观测现实性、规模效率和物理结构接口展开。
- **Research gap：** 强调已有方法已经利用天线轴和物理先验，缺口在于一维天线索引与二维 UPA 行-列拓扑不是等价接口；同时说明该判断关注模型接口显式性，不否定展平模型从数据中学习几何关联的可能性。
- **研究问题与方法：** 将四个子问题改为连续论证，并使方法部分分别回应阵元混合时机、token 坐标、二维相对几何和结构化掩码；删除重复的坐标条件化段落。
- **措辞与开题定位：** 统一使用“拟研究”“计划验证”“初步说明研究价值”等表述，减少自我防御式表达；实验部分保留单一数据集、单种子和训练时间增加等限制说明。
- **证据边界：** `Unknown` 字段未被改写为 `No` 或 `Yes`；未根据标题推断 ComHymba、WALoMA、AirFM-DDA、WiFo-INR 等工作的阵列结构。后续仍需对这些条目完成源码或全文级核验。
- **引用卫生：** 研究计划中提到的 prompt-guided multi-band CSI FM 在 `references.bib` 中已有 `huang2026promptguided` 条目，但本轮未新增正文引用；后续若正式讨论该工作，应补上对应 `\cite{}`。
