# WiFo 论文基准结果（提取自 arXiv:2412.08908）

> 本文档由 Claude 从 WiFo 论文 LaTeX 源文件提取，用于与 UPA 扩展模型的实验结果比对。
> 论文中的 NMSE 均为**线性值**（NMSE = ||H_P - H_GT||² / ||H_GT||²），不是 dB。
> 线性 NMSE 转 dB：`dB = 10*log10(NMSE)`。例如 0.210 → -6.78 dB，0.158 → -8.01 dB。
